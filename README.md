# MousyGenshinPreview

Sandeep's Genshin-themed portfolio: his GitHub profile README (github.com/SandeeepKiran), rendered the
way GitHub shows it, plus website-only extras GitHub cannot show:

- HoYoWiki's cursor, with a matching lit-up cursor on links and buttons.
- Element seals that pop up behind the contact buttons on hover (Email = Pyro, Telegram = Cryo,
  LinkedIn = Hydro, Portfolio = Geo, Resume = Electro).
- HoYoWiki's firefly backgrounds, changing element as you scroll.

It follows your light or dark theme.

- Live: https://sandeeepkiran.github.io/ (the main address, set by `live.txt` in sandeeepkiran.github.io),
  also https://sandeeepkiran.github.io/MousyGenshinPreview/ and `/Mousy-Portfolio/MousyGenshinPreview/`
- **Do not edit the files here by hand.** They are built by `tools/build_preview_branch.py` in the
  profile repo (SandeeepKiran/SandeeepKiran), which also keeps the sources and credits
  (`assets/source/README.md`). The stats cards are a snapshot from the day of the build.
- Branch of [Mousy-Portfolio](https://github.com/SandeeepKiran/Mousy-Portfolio). Keep `.github/workflows/ping-deploy.yml`.
