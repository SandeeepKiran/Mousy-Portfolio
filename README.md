# Sandeep Kiran's Portfolio — `david` design

One-page portfolio site. Plain HTML, CSS and JavaScript, with no build step and no dependencies.

- Live: https://sandeeepkiran.github.io/david/
- Branch of [Mousy-Portfolio](https://github.com/SandeeepKiran/Mousy-Portfolio). See `main` for how branches are published.

## Preview

- Double-click `index.html`, **or**
- Run `python -m http.server 8000` in this folder and open http://localhost:8000.

## Edit

- Text, links, email: `index.html`
- Project cards: `js/projects.js`
- Colours and fonts: top of `css/styles.css`

More detail: [`AGENTS.md`](AGENTS.md), [`docs/02-EDITING-GUIDE.md`](docs/02-EDITING-GUIDE.md).
