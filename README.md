# Sandeep Kiran's Portfolio — `jonny` design

Personal site of Sandeep Kiran, QA Manager at SoundHound AI.

- Live: https://sandeeepkiran.github.io/jonny/
- Branch of [Mousy-Portfolio](https://github.com/SandeeepKiran/Mousy-Portfolio). See `main` for how branches are published.
- Plain HTML and CSS in one file (`index.html`), no build step.
- Three colour themes: dark, light and mondstadt (a teal-green gradient). The choice is saved in the browser.
- Use relative links only (`./`, `assets/...`): the site is served from sub-folders like `/jonny/`.
